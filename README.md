# Kryvexora starter (demo)

This is the first front-end prototype, not a production earning app.

## Included
- Responsive mining dashboard
- Demo balance that increases while the page is open
- Demo daily claim and upgrade interactions
- Placeholder for AdsGram

## Not included yet
- Secure backend/database or Telegram user validation
- Persistent balances or server-verified mining
- Admin authentication and AI assistant
- Telegram channel-manager bot or scheduled posting
- Actual AdsGram integration
- Real deposits, withdrawals, or cryptocurrency payouts

KXC is a virtual game coin. The demo does not represent real money or promise payouts. The ad button intentionally does not show an ad or grant a reward.

## Next phases
1. Deploy the front end for review.
2. Add a backend with Telegram Mini App `initData` validation and a database.
3. Implement owner-only admin access, confirmations, and audit logs.
4. Build the Admin AI web chat and private Telegram interface.
5. Build the channel manager with per-channel permissions and on/off controls.
6. Integrate AdsGram only after checking current publisher requirements and approval.

Never put bot tokens, API keys, or database credentials in this repository.
